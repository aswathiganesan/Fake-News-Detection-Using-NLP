# Fake News Detection Using NLP

## Project Description

This project is a Fake News Detection system that uses Natural Language Processing (NLP) and Machine Learning to classify news articles as Fake or Real.

## Technologies Used

- Python
- Natural Language Processing (NLP)
- TF-IDF
- Machine Learning
- Calibrated Linear SVM
- Flask
- HTML
- CSS

## Project Features

- News text preprocessing
- TF-IDF feature extraction
- Fake/Real news classification
- Confidence/Credibility score
- Model explanation
- Confusion matrix
- Model performance visualization
- Flask-based web dashboard
