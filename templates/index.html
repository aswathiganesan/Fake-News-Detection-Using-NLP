About the Detection System

This project applies Natural Language Processing and machine learning to classify news articles into REAL and FAKE categories. The text is transformed into TF-IDF features, which are processed by a calibrated Linear SVM classifier.

The system provides the predicted class, confidence, class probabilities, estimated credibility, text statistics and model-related feature information.
